# مشروع APK لستالايت (جاهز بجسر الترويسات)

**الطريقة 1 — بدون تثبيت أي شيء (GitHub):**
1. أنشئ مستودعًا جديدًا في GitHub وارفع محتويات هذا المجلد كما هي.
2. من تبويب Actions شغّل «Build APK».
3. بعد دقائق حمّل `satellite-apk` من الـ Artifacts وثبّت `app-debug.apk`.

**الطريقة 2 — Android Studio:** افتح المجلد ← انتظر Sync ← Build ← Build APK.

لتحديث البرنامج: استبدل `app/src/main/assets/index.html` بآخر نسخة وأعد البناء.
الواجهة جاهزة: `SatBridge` (الترويسات) و`AccNative` (الاهتزاز) والكاميرا/المايك وملء الشاشة.
ملاحظة: لم أتمكن من بناء المشروع هنا (لا يوجد Android SDK في بيئتي)، فجرّب البناء أول مرة وأخبرني بأي خطأ.

## كارت الالتقاط (UVC) الأصلي — جديد
- في ستالايت: الأدوات ← مصدر خارجي ← زر «كارت التقاط USB (أصلي)» (يظهر داخل الـ APK فقط).
- يفتح شاشة أصلية تعرض الكارت عبر مكتبة UVC (libuvc) بدون الاعتماد على الكاميرا الخارجية في المتصفح.
- الصوت: إن وفّر الكارت صوت USB يُنقل إلى سماعة الهاتف.
- يعتمد البناء على JitPack (`com.github.shiyinghan:UVCAndroid`). **هذه الشاشة لم تُبنَ ولم تُجرَّب في بيئتي**، فإن ظهر خطأ بناء ألصقه لي لأصلحه.
- عند توصيل الكارت يسأل أندرويد عن إذن USB: وافق.
